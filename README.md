This repository is a tiny program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single line roasting a gadget or app used every day, written as UTF-8 bytes with no trailing newline into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), with the character count printed to stderr.

```text

```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
